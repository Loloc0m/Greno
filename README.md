# 🌿 Greno-Green

> "Small steps for a greener digital footprint."

**Greno-Green** is a creative web project dedicated to environmental awareness. It combines clean coding practices with a message of sustainability, focusing on how digital habits impact our planet.

[**🌍 Explore the Green World**](https://ala-esmat.github.io/Greno-Green/)

## 🌟 Highlights

- **Eco-Friendly Aesthetic:** Soft green palettes and nature-inspired UI elements.
- **Awareness Sections:** Engaging content layouts explaining environmental concepts.
- **Fast Performance:** Minimalist code for lightning-fast loading speeds.
- **Custom Illustrations:** Visual storytelling through optimized imagery.

## 🛠️ Technical Stack

- **Frontend:** HTML5, CSS3 (Custom Animations).
- **Functionality:** Vanilla JavaScript.
- **Performance:** High Lighthouse scores for accessibility and speed.

## 🚀 Mission

To demonstrate that web development can be a powerful tool for spreading environmental consciousness.
